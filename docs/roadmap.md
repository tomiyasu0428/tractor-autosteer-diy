# 製作の進め方

## 1. 対象車体と構成を確定

- [ ] 正式型式と電源仕様を確認する。
- [ ] [車体実測表](tractor.md)を埋める。
- [ ] 表示端末・ソフトウェア・版を決める。
- [ ] AIOの版、GNSS、IMU、ファームウェアをひとつの構成に揃える。
- [ ] モーターの電圧・軸・回転数・トルクと歯車比を決める。
- [ ] 手動解除・離脱・電源遮断の方式を決める。

完了条件: 型番・接続・主要寸法に矛盾がなく、購入候補を特定できること。

## 2. 初回購入と机上試験

- [ ] 最初の購入セットを[購入一覧](bom.md)にまとめ、価格・送料を確認する。
- [ ] 基板、端末、測位部品、電源、必要工具を調達する。
- [ ] 導通・極性・電源電圧を確認する。
- [ ] 採用した公式ファームウェアの版・取得元・設定を記録する。
- [ ] 端末とAIOの通信、GNSS出力、IMU出力を確認する。
- [ ] モーターを負荷から切り離した状態で駆動方向と停止を確認する。
- [ ] 舵角入力、手元解除、電源遮断、通信断時の挙動を確認する。

完了条件: 机上で各信号と停止条件を確認し、試験記録を残せること。

## 3. 機構の試作と車体取付

- [ ] 既存モデルの再利用可否とライセンスを確認する。
- [ ] 小さな寸法確認片からプリントして適合を確認する。
- [ ] 歯車、モーターホルダー、離脱機構を組み立てる。
- [ ] 全舵角・コラム調整・乗降時の干渉を確認する。
- [ ] WASリンクを仮組みし、全舵角と車軸揺動で限界を超えないことを確認する。
- [ ] ケース、端末、アンテナ、配線を固定する。

完了条件: 手動操舵に支障がなく、固定・配線・可動範囲を確認できること。

## 4. 有人で段階的に試験

- [ ] 停車状態で電源遮断・解除・回転方向を再確認する。
- [ ] 広く平坦な作業場所で低速の手動走行から始める。
- [ ] 車体寸法、アンテナ位置、IMU、舵角センサーを校正する。
- [ ] RTK補正と測位状態を確認してから自動操舵を試す。
- [ ] 通信・測位喪失時の解除挙動を検証する。
- [ ] 走行条件、設定、直進性、発熱、緩み、改善点を記録する。

完了条件: 条件と結果を明記した試験記録を共有し、残る不具合をIssueとして管理できること。
