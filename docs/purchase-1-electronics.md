# 第1次購入リスト（電子部品・机上試験用）

作成日: 2026-11-03

車体の採寸を待たずに注文できる電子部品・配線・工具をまとめた。価格はWeb検索で得た参考値と概算で、**注文前に販売ページで価格・送料・在庫を必ず確認する**。外貨の換算は 1 USD = 155円、1 EUR = 175円 と仮定した。

確定した構成: AIO Micro v4.5、Teensy 4.1、ZED-F9P（シングル）、BNO085、Cytron MD13S、Android＋AgOpenWeb（[判断の記録](decisions.md)）。

## AIO Micro v4.5 で分かったこと

公式リポジトリ [AgOpenGPS-Official/Boards](https://github.com/AgOpenGPS-Official/Boards) の `TeensyModules/AIO Micro v4/PCB Build/AIO v4.5 Micro` を確認した。

- 基板はJLCPCBに部品実装込みで発注する（Gerber・BOM・CPLが公開されている）。
- **基板に実装済み**: LANコネクター（RJ45）、電流センサー（ACS712 5A）、AMPSEAL 23ピン（776087-1）、電源レギュレーター、WAS用AD変換（ADS1115）、ヒューズホルダー（Mini ATO）。
- 電流検知による解除は、基板上のACS712で対応する。説明書には「電流検知ならジャンパー不要」とある。
- **別に購入する部品**: Teensy 4.1、ZED-F9P（simpleRTK2B Micro形状）、BNO085（Adafruit形状）、Cytron MD13S、Mini ATOヒューズ、AMPSEALの相手側プラグ、ケース。
- ケースは3Dプリント用STLが同じ場所にある（`Enclosures/3Dprint/Micro_AMP`）。フィラメント代だけで作れる。
- 参考価格: 2024年の作者見積もりでは、5枚・部品実装込みで $224.24（部品代 $141.40）。

## 予算について

- 上限15万円に対して、電子部品と工具だけで約12.5〜14万円になる見込み。ここにモーター（1万円前後）、フィラメント、送料・関税が加わると上限に近いか、超える。
- 高いのは **ZED-F9P基板（約3.5万円）** と **AIO基板（2〜3.5万円）**。基板は最低2枚から発注になるので、余った基板を仲間と分けると1台あたりの費用を下げられる。
- Android端末は手持ちを使う前提で、この表に入れていない。新しく買う場合は別に予算が必要。

## 注文前の確認

- [ ] JLCPCBで公式ファイルを見積もり、枚数・部品の在庫切れ・代替部品（`JLCPCB ALTERNATE PARTS.xlsx`）を確認する。
- [ ] ZED-F9P基板のピン配置がAIO Microのソケット（2mmピッチ・10ピン×2列）に合うか確認する。
- [ ] BNO085のピン配置がAdafruit 4754と同じか確認する。
- [ ] 各購入先で税込価格・送料・到着日数を確認し、[購入・自作一覧](bom.md)に品番・URL・確認日を記入する。

## このリストに入れていないもの（採寸後）

モーター（M01）、WASの取付リンクと金具（M05・M06）、歯車・ホルダーなどの3Dプリント部品（P01〜P04）。モーターは机上試験で回すために先に買ってもよいが、操舵負荷を測ってから決める方が買い直しの心配がない。
