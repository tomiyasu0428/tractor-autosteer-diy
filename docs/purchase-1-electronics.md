## AIO Micro v4.5 で分かったこと

公式リポジトリ [AgOpenGPS-Official/Boards](https://github.com/AgOpenGPS-Official/Boards) の `TeensyModules/AIO Micro v4/PCB Build/AIO v4.5 Micro` を確認した。

- 基板はJLCPCBに部品実装込みで発注する（Gerber・BOM・CPLが公開されている）。
- **基板に実装済み**: LANコネクター（RJ45）、電流センサー（ACS712 5A）、AMPSEAL 23ピン（776087-1）、電源レギュレーター、WAS用AD変換（ADS1115）、ヒューズホルダー（Mini ATO）。
- 電流検知による解除は、基板上のACS712で対応する。説明書には「電流検知ならジャンパー不要」とある。
- **別に購入する部品**: Teensy 4.1、ZED-F9P（simpleRTK2B Micro形状）、BNO085（Adafruit形状）、Cytron MD13S、Mini ATOヒューズ、AMPSEALの相手側プラグ、ケース。
- ケースは3Dプリント用STLが同じ場所にある（`Enclosures/3Dprint/Micro_AMP`）。フィラメント代だけで作れる。
- 参考価格: 2024年の作者見積もりでは、5枚・部品実装込みで $224.24（部品代 $141.40）。

## モーターの選び方

モーターは電動のDCギアモーター（12Vブラシ付き）。3Dプリントした歯車（ピニオンとハンドル側のリングギア）でハンドルを回す。

| 目標 | 値 | 根拠 |
|---|---|---|
| ハンドルの回転速度 | 毎分80〜120回転 | AgOpenGPSフォーラムで約100rpmが目安とされる。遅いとUターンに追いつかない |
| ハンドルを回すトルク | 5〜10N·m | パワステ付きで手で回す力は約2N·mという実測例があり、余裕を持たせる |
| 3Dプリント歯車の減速比 | 3:1〜4:1 | 出力250〜400rpmのモーターと組み合わせて上の2つを満たす |
| 電流 | 連続10A以下 | Cytron MD13Sの定格は13A。AIO基板の配線とヒューズを考えて10A以下に抑える |

- **ウォームギア式は外から回せないので使わない。** 遊星ギア式も手では重いので、物理離脱レバーで歯車を外す前提は変わらない。
- 歯車比は3Dプリントで後から変えられる。操舵負荷を採寸前に買っても、トルクが足りなければ歯車比で調整できる。
- フォーラムでは、プラスチック歯車が噛み込んで約70Wのモーターが焼損し、10Aヒューズが何本も切れた例がある。机上試験から電流制限とヒューズを必ず使う。
- 参考: 完成品の操舵モーター（Keya製のブラシレス・CAN制御、100rpm・ピーク13N·m）もAliExpressで売られている。ただしハンドルの交換とCAN対応が必要になり、この計画のギアモーター方式とは別物になるため採用しない。

## 予算について

- 上限15万円を超えてもよいことになった（2026-11-03 ユーザー確認）。
- 電子部品・工具・モーターで約13.5〜15.5万円の見込み。フィラメント、送料、関税は別。
- 高いのは **ZED-F9P基板（約3.5万円）** と **AIO基板（2〜3.5万円）**。基板は最低2枚から発注になるので、余った基板を仲間と分けると1台あたりの費用を下げられる。
- Android端末は手持ちを使う（ユーザー確認）。
