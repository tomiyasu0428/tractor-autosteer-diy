# 操舵機構の課題と企画

作成日: 2026-11-04
対象: ISEKI BIG-T 5095（運転席写真で確認）

モーターでハンドルを回す機構について、分かっている課題と、進め方の案をまとめる。採寸結果が入ったら、この資料を更新して設計に進む。

## 1. 現状

- 方針は「純正ハンドルを残し、12V遊星ギアモーター＋3Dプリント歯車で回す」（[判断の記録](decisions.md)）。
- 運転席の写真から、ハンドルはコラムのカバーにほぼ密着している。ハンドルのすぐ下に蛇腹があり、チルトの支点がそこにある可能性がある。
- ハンドル右側のリムにスピンナーノブが付いている。右側はギアレバーで込み合っている。
- 採寸はまだ。隙間・チルトの動き方・スポーク裏の形が未確認。

## 2. 課題

| # | 課題 | 影響 | 現時点の見立て |
|---|---|---|---|
| K1 | **ハンドル裏の隙間が狭い** | リングギアとピニオンを入れる空間がない | モーターをハンドル真下ではなく**コラムの横に縦置き**にすれば、スポーク裏に1.5〜2cmあれば足りる。要実測 |
| K2 | **チルト支点の位置** | 支点がハンドル直下（蛇腹）なら、チルトでハンドルだけ傾き、カバーに付けたモーターとの噛み合いが外れる | チルトを1か所に固定して使うか、チルト操作を離脱に使う。要確認 |
| K3 | リングギアの同心出し | 回転中心とずれると、1回転の中で噛み込む | 分割リングの固定穴を長穴にして調整。歯なしの輪で先に振れを確認 |
| K4 | モーターの反力をプリント品で受ける | 5〜10N·mが台にかかり、PETGの穴が広がる | モーターのフランジは金属プレート、ヒンジのピンは金属ボルト |
| K5 | コラムカバーが樹脂 | クランプしても回る、割れる | カバーの下に金属筒があるか確認。なければ金属バンドで広く挟み、ゴムシートを入れる |
| K6 | スピンナーノブの金具 | リングギアと干渉する | リングギアの外径をノブ金具より内側にするか、ノブを付け直す |
| K7 | 手動操舵時の重さ | 遊星ギアは外から回すと重い | 物理離脱レバーは必須（K2の対処と兼ねられる可能性） |

## 3. 選択肢

| 案 | 内容 | 費用の目安 | 利点 | 難点 | 採否 |
|---|---|---|---|---|---|
| **A0. コラム横に縦置き**（基本案） | スポーク裏にリングギア、ピニオン上向きのモーターをコラムカバーの横（左か前）に吊るす | 1〜2万円（モーター込み） | 隙間が1.5〜2cmあれば成立。純正ハンドルそのまま | K2〜K6の対処が必要 | **第一候補** |
| A1. ハンドルのかさ上げ | 軸とハンドルの間にスプライン付きスペーサーを入れて裏に空間を作り、A0と同じ機構 | ＋数千円〜1万円 | A0が隙間不足のときの逃げ道 | スプライン規格に合うアダプターが要る。ハンドルが手前に出る | A0が無理なら |
| B. モーター一体型ハンドルに交換 | 純正ハンドルを外し、Keya製などの完成品を軸に直付け。CAN制御 | 6〜8万円 | 狭いキャブの定番。歯車・離脱・台の自作が不要 | 高い。AIO MicroのCAN配線。AgOpenWebのKeya対応は未確認 | A0・A1が無理なとき |
| C. リム外側から摩擦駆動 | ゴム車輪をリムの外側に押し付けて回す | 1万円前後 | 隙間・同心が不要 | 大きな力で滑る。実績が少ない | 保留 |

## 4. 判断に必要な実測（これで決まる）

| # | 確認すること | 判断 |
|---|---|---|
| 1 | チルトを動かしたとき、蛇腹の下のカバーが一緒に動くか（横から上・下の写真2枚） | 動く → カバーに固定でよい。動かない → チルト固定運用か、チルトを離脱に使う |
| 2 | スポーク裏からカバー上面までの隙間（中心から10〜15cm外側、定規を差し込む） | 2cm以上 → A0。1.5cm未満 → A1かB |
| 3 | ハンドル真下からの写真（スポーク裏の形、カバー周りの空き） | リングギアの固定方法と、モーターを吊るす側（左／前）を決める |
| 4 | カバーの下の金属筒の有無、カバーの外径・幅 | クランプの形を決める（K5） |
| 5 | 中央キャップ内のナットと軸のスプライン（写真） | A1に進む場合だけ必要 |

残りの採寸（リム外径、スポーク寸法、操舵負荷、ロック間回転数）は[対象トラクターと実測項目](tractor.md)の採寸ガイドのとおり。

## 5. 進め方（A0の場合）

1. **実測と写真** — 上の5項目。これでA0／A1／Bを決める。
2. **歯なしの輪を試し印刷（PLA）** — スポーク裏に付けて手で回し、振れと固定方法を確かめる。長穴の調整幅を決める。
3. **モーター到着後、台を仮組み（PLA）** — コラム横に吊るし、ピニオンとの噛み合い深さを長穴で調整。モーターのフランジは金属プレート。
4. **離脱の方式を決める** — ヒンジ＋トグルか、チルト操作を離脱に使うか。手で素早く外せること、走行の振動で外れないことを確認。
5. **PETGで本番印刷** — 寸法が固まってから。歯車は後から歯数を変えられるので、トルク不足は歯車比で調整。
6. **机上での噛み合わせ試験** — 車体に付ける前に、モーターを回して歯車の噛み込み・発熱・電流を見る。ヒューズと電流制限を必ず使う。
