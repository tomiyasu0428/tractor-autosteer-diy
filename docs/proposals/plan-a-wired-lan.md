# プランA：有線LAN統合型スマート自動操舵システム

記録日: 2026-11-03 / 状態: 提案・未採用・未実装・未検証

追補: [部品・ソフト適合の最新進捗](../progress/2026-11-03-component-and-firmware-review.md)を参照。以下の元案は保存し、部品候補と屋根分離／PoEの採否を別々に検討している。

ユーザー提出の「オープンソース版『CHCNAV風』スマート自動操舵システム企画書」の要旨を整理した資料。全文の逐語転載ではない。「CHCNAV風」は機器配置・見た目の着想を示す呼称で、同社との関係や同等性能を意味しない。AOGを利用する案であり、GNSS受信機の内部ファームウェアを含む全構成のオープンソース性は確認していない。

## 対象と目的

- 対象は別途新規に製作するISEKI95馬力機。正式型式は未確認。
- 現在の別トラクターは現在の構成で完結させ、本案では変更しない。
- 自動操舵部品はゼロから新規調達する前提。品番・購入先・価格は未選定。
- キャビン内で目立つものをタブレットと操舵モーター程度に抑える。ピラー上の大きなAIO Standard箱や多極カプラー、屋根から長く引く硬いSMA同軸を減らす。
- 純正ハンドルを残し、ブラシ付きDCギアモーターで歯車を介して操舵する候補。既存別機のCANモーターを流用する案ではない。

## 概念接続図

```text
[屋根: パッチGNSS x2 --短い同軸-- UM982 + MCU + PoE受電側]
                          |
                   LAN + PoE 1本
                          |
            [足元: LANスイッチ + 対応PSE給電機能]
                 |                         |
             LAN 約30cm                   LAN
                 |                         |
 [隠蔽操舵箱: MCU/ADC/Hブリッジ]      [CF-20等タブレット]
        |           |          |
   DCモーター2線  WAS3線   操舵ON/OFF
```

元案の配線図はタブレット接続までで終わっているため、その先の配線は補っていない。これは機能上の概念図で、実配線図やピン数の確定ではない。PSEはスイッチ内蔵／別置とも未選定。通常の非PoEハブだけでは屋根へ給電できない。操舵箱・モーター・スイッチ・タブレットの電源や保護配線は別途設計が必要であり、「車内の総配線が図の本数だけ」とは意味しない。

## 元案の主張と確認状態

| 主張・目標 | 記録時点の扱い |
|---|---|
| 二アンテナならIMUを完全撤去できる | 条件付き検討。単基線の姿勢観測限界、車両座標変換、AOG入力、動的性能・欠落処理の検証が必要 |
| 停車中でも方位0.1° | UM982公称値は1m基線の条件付き仕様。完成機の停車・圃場性能保証ではない |
| 低速・後退でもふらつかない | 達成目標。車両・操舵制御・方向判定・測位品質を含む未検証の主張 |
| 薄い黒いパッチでキノコ型を置き換える | 外観だけでは選べない。対応帯域等の適合を確認する |
| LANなら切断・干渉が100%ない | 誤り。UDP配送保証や電源・コネクターの故障排除はない |
| PoEで屋根への別電源線を減らせる | 対応PSE/PD・電源変換・電力収支がそろえば成立しうる |
| 小型箱に一式収まる | 収納・放熱・端子・保護部品・整備空間を含めて未検証 |
