# ISEKI 95馬力機 プランA 独立技術評価

※私はUM982、BTS7960、AOGの一次資料を独自に照合していません。提示された前提以外の仕様は一般的な知見に基づく推定です。

## 1) 結論(条件付き推奨)

**試作としては条件付きで推奨します。圃場投入は保留です。**
以下の4点が実測で確認できるまでは、デモ機の位置づけに留めるべきです。

- アンテナの帯域と基線剛性
- 方位喪失時の停止動作
- モーターの手動解除性
- 車載電源への適合

## 2) 重大な誤認

- **「停車方位0.1度」**: 1m基線・良好環境での仕様値です。実機の基線長、マルチパス、屋根のたわみで劣化します。
- **「IMU不要で低速・後退も安定」**: 方位は得られます。ただしRTK Fix喪失時の補完、ロール補償、ヨーレートは得られません。
- **「LANなら確実」**: UDPは配送保証がありません。PoEはPSE/PDが揃わなければ給電されません。
- **「12V/5Vでスイッチ給電可」**: 車両電源はクランキング時の電圧降下やロードダンプがあり、市販スイッチがそのまま耐えるかは未確認です。

## 3) 薄型パッチアンテナ

- **帯域**: UM982のマルチバンド性能を活かすには、アンテナ側が使用帯(L1/L2/L5等)に対応している必要があります。薄型品はL1単帯の例が多く、要確認です。
- **能動給電**: LNAへのバイアス電圧と電流が受信機出力と合うか確認が必要です。
- **グランドプレーン**: 寸法とアンテナの要求が合うか確認します。屋根がFRPか金属かで特性が変わります。
- **位相中心**: 2個を同一型式・同一向きで揃えると位相中心変動の影響を抑えられます。
- **耐環境**: 防水、UV、振動、ケース貫通部の防水処理が必要です。
- **基線剛性**: 薄いバーのたわみや振動がそのまま方位誤差になります。1mで1mmのずれが約0.06度に相当します。

## 4) IMU省略の条件と単基線幾何

- 単基線では、基線軸周りの回転は観測できません。
- 左右配置の場合:
  - 得られるのは方位(90度オフセット補正後)とロールです。
  - ピッチは得られません。
  - 屋根高約3mでロール5度なら、横誤差は約26cmになります。ロール補償は必須です。
- IMUを省略できる条件:
  - 開空で平坦な圃場に限定する
  - RTK Fixを常時維持できる
  - 20Hzと遅延を含めた制御で発振しない
  - 方位無効時に即座に操舵を解除する

## 5) DCギアモーターとBTS7960

- **拘束電流**: 据切りや轍での実負荷トルクを先に測定し、拘束電流と温度上昇で余裕を確認します。
- **熱**: 名刺〜タバコ箱サイズでは放熱面積が不足する懸念があります。
- **手動解除**: ギア比が高いと逆駆動が重く、運転者が操舵しにくくなります。クラッチ等の機械的切離しを推奨します。
- **機械干渉**: 膝やキャビン内部材との干渉確認が必要です。
- **BTS7960**: 試作には適します。ただし廉価モジュールは品質のばらつき、電流検出精度、ヒューズ、逆接保護、回生対策が未保証です。

## 6) 通信途絶時の安全

- **ローカルwatchdog**: 一定時間有効パケットがなければ、MCU単独でH-bridgeを無効化します。
- **手動遮断**: MCUを介さない物理スイッチやリレーで電源を遮断できるようにします。
- **復旧時の自動再開禁止**: 通信が戻っても自動で再開せず、運転者の再エンゲージを必須にします。

## 7) 段階的検証計画

1. 机上: 電源の電圧変動試験、watchdogの動作確認
2. 静置: 方位統計(基線長と屋根たわみを含む)
3. 架台: モーターの拘束・発熱・逆駆動試験
4. 実車停止状態: 操舵ON/OFFと手動介入
5. 低速直進 → 旋回 → 後退
6. 遮蔽・Fix喪失時の挙動確認

AOG/AgIOとファームウェアの版は固定して検証します。

## 8) 採用前の未知情報

- 正式型式と操舵方式(油圧オービットロール等)
- 必要操舵トルク
- 電源系(電圧と許容負荷)
- 屋根の材質と取付点
- アンテナ型式と帯域
- スイッチの車載耐性
- MCUの具体構成(TeensyのMagJack要否、ESP32のPHY型番)

本案は市販CHCNAV等と同等の性能も、絶対的な安全も保証できません。上記の実測で一つずつ判断してください。
