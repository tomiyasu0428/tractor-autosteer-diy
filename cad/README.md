# 3Dモデルの管理

モデルはまだ登録されていません。取付対象を実測し、モーター・基板・ケースを選定した後に追加します。

対象候補はリングギア、ピニオン、モーターホルダー、コラム固定具、ケース、車体固定具、WAS保護カバーです。

各モデルには次を添えます。

- 編集可能な元データと出力ファイル。
- 実測した寸法と適合する部品品番。
- プリンター・造形範囲・ノズル、材質、造形方向、必要な支持材、壁・充填設定。
- ボルト、ナット、軸受等の必要品。
- 寸法確認・仮組み・負荷試験の結果。
- 外部モデルを使う場合は取得元とライセンス。

プリンターを所有していることと、フィラメント・締結部品が手元にあることは区別します。実測・材質・試験結果が揃うまで、モデルを実機適合済みとして扱いません。
