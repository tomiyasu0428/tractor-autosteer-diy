# トラクター自動操舵 DIY

ISEKI 95馬力トラクターに、AgOpenGPSとDCギアモーターによる自動操舵を取り付ける共同製作プロジェクトです。純正ハンドルを残し、3Dプリントした歯車を介してモーターで回す方式を検討します。

現在は部品選定・設計前の段階です。完成した設計、配線図、ファームウェア、動作実績はまだありません。

## 確定した前提

- 取付対象は農場台帳に登録された「ISEKI 95」。正式型式は未確認です。
- 自動操舵用の手持ち部品はゼロとして、すべて新規調達します。
- 3Dプリンターを利用できます。フィラメント、ボルト、工具、電源、表示端末も必要なものは予算に含めます。
- 最初の1台を製作します。基板を複数枚発注する場合も、初回に支払う総額を管理します。
- 純正ハンドルを使うギアモーター方式を軸に、机上試験から進めます。

## 最初の作業

1. 車体銘板・取扱説明書で正式型式と電源仕様を確認する。
2. ハンドル周辺、前輪舵角センサー取付部、ケース固定候補を実測する。
3. 表示端末、AIO基板の版、GNSSボード、モーターと歯車比の組合せを決める。
4. 実売価格・送料を確認し、机上試験に必要な最初の購入セットを作る。

## 試験の前提

モーターを車体に接続する前に、回転方向、信号喪失時の停止、手元での電源遮断、手動操舵への復帰を確認します。車体での試験は有人・監視下で段階的に進めます。このリポジトリで無人運転や公道での自動操舵を設計対象にはしていません。

農場の台帳そのもの、圃場位置、個人情報、認証情報は含めません。共同作業に必要な機体仕様と製作記録を管理します。
